# Ảnh khách sạn

Thay các tệp JPEG giữ chỗ (1 × 1 px) bằng ảnh thật cùng tên:
- hero.jpg: ảnh ngang, đề nghị 1920 × 1080 px trở lên.
- phong-standard.jpg, phong-deluxe.jpg, phong-family.jpg: ảnh ngang, đề nghị 1000 × 700 px trở lên.

Trình duyệt tự hiện ảnh có kích thước lớn hơn 1 px; nếu chưa có ảnh hoặc ảnh lỗi, giao diện hiện gradient xanh rêu cùng tên phòng/icon. Không cần sửa HTML hoặc JavaScript. Tải lại trang sau khi thay ảnh; nếu chạy từ JAR, đóng gói và chạy lại để đưa ảnh mới vào ứng dụng.
